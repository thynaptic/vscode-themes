## About

Thynaptic delivers three professionally designed color themes for Visual Studio Code, built on a foundation of neutral surfaces and refined typography. Each theme is engineered to minimize eye strain while maintaining exceptional contrast and readability across all syntax elements.

Whether you prefer bold contrast, softer tones, or warm naturals, Thynaptic has a theme tailored to your development environment and workflow.

## Features

✨ **Neutral-First Design** – Clean, distraction-free surfaces that keep focus on your code

🎨 **Consistent Brand Accent** – Sophisticated Thynaptic blue used strategically for visual cohesion

⚡ **Semantic Color System** – Utility colors reserved exclusively for warnings, errors, and status indicators

🌓 **Three Variants** – Dark, Dim, and Sand themes to match any environment and preference

👁️ **Optimized Contrast** – Carefully calibrated color values for readability and reduced eye fatigue

🎯 **Professional Polish** – Every detail refined for a premium development experience

## Themes

### Thynaptic Dark

High-contrast theme with a neutral-first color scheme anchored by sophisticated Thynaptic blue. Ideal for standard lighting conditions and developers who prefer darker interfaces.

- **Base Color**: Deep neutral black
- **Accent**: Thynaptic blue
- **Best For**: Well-lit environments, standard development workflows

### Thynaptic Dim

Softer contrast variant maintaining the same color philosophy as Dark. Perfect for dimly lit environments or extended coding sessions that demand clarity without intensity.

- **Base Color**: Soft dark charcoal
- **Accent**: Muted Thynaptic blue
- **Best For**: Low-light environments, reduced eye strain, long sessions

### Thynaptic Sand

Warm light theme inspired by natural paper and sand tones. Matches the refined aesthetic of thynaptic.com and suits bright environments or preferred light-mode workflows.

- **Base Color**: Warm sand/paper
- **Accent**: Thynaptic blue on light background
- **Best For**: Bright environments, light-mode preference, natural aesthetics

## Installation

### VS Code Marketplace

1. Open **Visual Studio Code**
2. Open the **Extensions** sidebar (Ctrl+Shift+X / Cmd+Shift+X)
3. Search for **"Thynaptic Color Themes"**
4. Click **Install**

### Activate a Theme

1. Open the **Command Palette** (Ctrl+Shift+P / Cmd+Shift+P)
2. Type **"Color Theme"**
3. Select **Preferences: Color Theme**
4. Choose your preferred Thynaptic theme

## Customization

To customize these themes, you can extend them in your VS Code `settings.json`:

```json
"workbench.colorCustomizations": {
  "[Thynaptic Dark]": {
    "editor.background": "#1a1a1a",
    "editor.foreground": "#e0e0e0"
  }
}
```

See the [VS Code theme documentation](https://code.visualstudio.com/docs/getstarted/themes) for advanced customization options.
