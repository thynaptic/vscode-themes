# Changelog

## 0.3.0
- Add **Thynaptic Sand Dark** dark variant (warm dark sand style).
- Update **Thynaptic Dark (Base)** and **Thynaptic Dim (Base)** to remove blue accent colors.
- All themes now use neutral color palettes aligned with Thynaptic brand identity.
- Keywords, functions, and code elements now use foreground colors for clean, minimal aesthetic.

## 0.2.0
- Add **Thynaptic Sand (Base)** light variant (warm paper/sand style).

## 0.1.0
- Initial release of **Thynaptic Dark (Base)** and **Thynaptic Dim (Base)**.
- Neutral-first palette with Thynaptic blue accent; intentionally excludes teal/pink hues.
